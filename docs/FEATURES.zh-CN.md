# 功能清单

[English](FEATURES.md)

网关目前支持什么、还不支持什么。标为「尚未支持」的条目只是为了让你看到缺口，列出来并不代表承诺以后会实现。已支持功能的细节见 [README](../README.zh-CN.md)。

✅ 已支持 · 🟡 部分支持 · ⬜ 尚未支持

## 私聊

| 功能 | 状态 |
|---|---|
| 收发文本（数组或 CQ 码字符串格式） | ✅ |
| OMEMO 加密（旧版 `eu.siacs.conversations.axolotl`），盲信任或手动信任，会话失步恢复 | ✅ |
| 用 OMEMO `urn:xmpp:omemo:2` 发送 | ⬜ 尚未支持 |
| OMEMO 密钥加密存储（目前为权限 600 的 JSON） | ⬜ 尚未支持 |
| 图片、语音、视频、文件双向收发（HTTP Upload + OOB；OMEMO 会话中为 `aesgcm://`） | ✅ |
| 回复引用（XEP-0461） | ✅ |
| 撤回机器人自己的消息；联系人撤回时发送撤回通知 | ✅ |
| 送达回执（XEP-0184） | ✅ |
| 从服务器存档补取离线消息（XEP-0313 MAM） | ✅ |
| 好友请求：自动同意，不上报给机器人框架 | 🟡 |
| 好友请求事件及同意 / 拒绝 / 删除好友接口 | ⬜ 尚未支持 |
| 消息编辑（XEP-0308） | ⬜ 尚未支持 |
| 表情回应（XEP-0444） | ⬜ 尚未支持 |
| 「正在输入」状态（XEP-0085） | ⬜ 尚未支持 |

## 群聊（MUC）

| 功能 | 状态 |
|---|---|
| 加入配置的群、创建新群、重连后重新进群 | ✅ |
| 群邀请（XEP-0045 与 XEP-0249），可配置信任哪些邀请者 | ✅ |
| 收发群消息、@、回复、媒体 | ✅ |
| 撤回通知、从群存档补取离线消息 | ✅ |
| 稳定的成员身份（真实 JID 或 XEP-0421 occupant-id） | ✅ |
| 群列表、群信息、成员列表、成员信息、退群 | ✅ |
| 群聊 OMEMO（加密群消息会被忽略） | ⬜ 尚未支持 |
| 成员进群 / 退群通知（`group_increase` / `group_decrease`） | ⬜ 尚未支持 |
| 踢人（`set_group_kick`） | ⬜ 尚未支持 |
| 禁言单人或全员（`set_group_ban` / `set_group_whole_ban`） | ⬜ 尚未支持 |
| 设置管理员（`set_group_admin`）及管理员变动通知 | ⬜ 尚未支持 |
| 修改机器人群昵称或群名 / 主题（`set_group_card` / `set_group_name`） | ⬜ 尚未支持 |
| 群邀请请求上报给框架（`request.group` / `set_group_add_request`） | ⬜ 尚未支持 |
| 与群成员的私信作为独立会话 | ⬜ 尚未支持 |
